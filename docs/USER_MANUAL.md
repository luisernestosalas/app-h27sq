# Manual de Usuario - CRM con Clientes y Notas

## ¿Qué es esta aplicación?

Es un sistema simple para gestionar clientes y sus notas. Te ayuda a:
- Guardar información de tus clientes
- Agregar notas sobre cada cliente
- Buscar clientes rápidamente
- Organizar tu información de ventas

## Cómo acceder

**Dirección web:** https://app-h27sq-4sfimslq4-luisernestosalas-2775s-projects.vercel.app

Solo necesitas un navegador web. No requiere instalación.

## Pantalla principal

Al abrir la app verás:
- **Lista de clientes** en el lado izquierdo
- **Detalles del cliente** en el lado derecho
- **Barra de búsqueda** arriba
- **Botón "Nuevo Cliente"** para agregar

## Cómo usar la aplicación

### 1. Agregar un nuevo cliente

1. Haz clic en **"Nuevo Cliente"**
2. Completa los campos:
   - Nombre (obligatorio)
   - Email
   - Teléfono
   - Empresa
3. Haz clic en **"Guardar"**

### 2. Ver información de un cliente

1. Busca el cliente en la lista izquierda
2. Haz clic sobre su nombre
