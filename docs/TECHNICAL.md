# Documentación Técnica - CRM App H27SQ

## Información General

**Aplicación:** CRM con gestión de clientes y notas  
**Stack Tecnológico:** HTML + JavaScript (Vanilla)  
**Repositorio:** https://github.com/luisernestosalas/app-h27sq  
**URL de Despliegue:** https://app-h27sq-4sfimslq4-luisernestosalas-2775s-projects.vercel.app

## Arquitectura

### Frontend
- **HTML5:** Estructura y marcado semántico
- **JavaScript ES6+:** Lógica de aplicación, manipulación DOM
- **CSS3:** Estilos y diseño responsivo (asumido)

### Características Principales
- Gestión de clientes
- Sistema de notas asociadas
- Interfaz web responsive
- Almacenamiento local (localStorage/sessionStorage probable)
