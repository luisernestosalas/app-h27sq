# CRM App - Gestión de Clientes y Notas

Una aplicación web simple y eficiente para la gestión de clientes y sus notas asociadas, desarrollada con tecnologías web nativas.

## 🚀 Características

- **Gestión de Clientes**: Crear, editar, eliminar y visualizar clientes
- **Sistema de Notas**: Agregar y gestionar notas para cada cliente
- **Interfaz Intuitiva**: Diseño limpio y fácil de usar
- **Almacenamiento Local**: Los datos se guardan en el navegador
- **Responsive**: Compatible con dispositivos móviles y desktop

## 🛠️ Stack Tecnológico

- **HTML5**: Estructura y marcado semántico
- **JavaScript**: Lógica de negocio y manipulación del DOM
- **CSS3**: Estilos y diseño responsive
